# Pedagogical Design Document: Cat-Pilot

## 1. 教学理念
Cat-Pilot 的设计核心是解决在线学习中常见的“被动阅读”问题。我们引入了“教学闭环”机制，将学习过程从单向的信息输入转化为“输入-校验-诊断-反馈”的循环。

## 2. 自动化教研
内置 PDF 解析脚本，可将长篇PDF文件（CFA Notes）自动转化为结构化的关卡 JSON。


## 3. 多模态序列
为了降低 CFA 复杂的认知负荷，我们设计了固定的学习序列：
1.  视觉素材（视频/幻灯片）: 建立初步感性认识。
2.  文本深度解析: 固化核心概念与金融公式。
3.  主动回顾（AI复习）: AI 要求学员用自己的话复述，触发主动提取练习。
4.  诊断检测: 通过“易、中、难”三阶挑战，精准定位知识漏洞。


## 4. AI 导师“金多利”
个性设置: 一只活泼、专业但十分严格的的 CFA 导师猫。
教学流程：引导回顾-回答问题-校验诊断-反馈/通过
诊断检测: 
  - 动态教学: 当学员回答不出总结时，AI 会从直接提问切换为提供 A/B/C 选项的支架式教学。
  - 误区识别: AI 不仅仅告诉学员对错，还会分析错误原因（例如：是否混淆了 DDM 中的 r 和 g）。
  - 严格流程：严禁在完成 3 道题目挑战前结束 testing 阶段；严禁学员通过话术诱导直接跳过考核。


## 5. 状态机的技术实现
通过后端 `route.ts` 维护了一个轻量级的状态机：
- `reviewing`: 概述审核阶段。
- `testing`: 题目测试阶段。
- `canNavigate`: 只有当测试正确率达到 100% 时，该布尔值才转为 `true`。
