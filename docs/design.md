# Pedagogical Design Document: Cat-Pilot

## 1. 项目出发点：从“被动问答”转向“主动教学”
目前的 AI 学习工具大多存在一个核心缺陷：它们在本质上是“被动”的。这种基于“用户提问，AI 回答”的搜索引擎式交互，虽然便于信息检索，却无法承载真正的教学功能。
真正的教学应当具备逻辑导向的内容呈现、实时的理解程度校验、动态的节奏控制，以及对学科直觉的深度培养。传统的问答式 AI 无法满足这些要求，因此我开发了 Cat-Pilot。
Cat-Pilot 是一款基于 Next.js 16 与 DeepSeek API 构建的“关卡式”教学系统。通过内置的 AI 导师——“金多利”（Kindori），本系统实现了从“被动检索”到“主动干预教学”的范式转变。

## 2. 设计迭代历程：复盘与迭代
在形成最终形态前，Cat-Pilot 经历了两个核心版本的迭代：

第一阶段：关键词触发机制
  - 页面设计：采用传统的左右分布聊天框。
  - 教学流程：系统提炼章节关键词，引导学员触发指定词汇以推进课程。
  - 复盘：该模式导致 AI 异化为单纯诱导关键词的工具，而非引导理解。学员可以通过“复制粘贴”教学内容来欺骗系统，使学习流于表面，未能触达教育本质。

第二阶段：结构化测试模式
  - 页面设计：保留一阶段布局，引入“答题通关”逻辑。
  - 教学流程：通过考试检测学员的学习情况，实行答题通关制度。
  - 复盘：虽然增强了对学习效果的判断，但交互形式仍局限在传统聊天框内，未能解决“多模态沉浸感”缺失与“学习节奏失控”的问题。它本质上仍是一个挂载了题库的插件，而非完整的教学系统。


## 3. 核心设计：最终版产品形态
### 3.1 陪伴式导师：拟人化“金多利”设计
我设计了“金多利”这一极具辨识度的 CFA 导师形象。
  - 情感价值：通过可爱的拟小猫化视觉效果，配合活泼且严厉的性格设定，激发学员的互动欲望，将冰冷的对话窗口转化为具备性格的学习伙伴。
  - 全局交互：导师始终贯穿于主页与学习页右下角。通过循环的语境提示（"CFA 备考路漫漫，金多利陪你转喵！🐾","建议按 1→2→3→4 的顺序学习，地基稳才行喵！",“上次学到...，继续加油喵！✨ : "点击下方章节，开始今天的挑战吧！","每一小节都要通过我的 3 题考核才能过关喔！🎓"）实时引导学习进度，并在首页根据学员的历史进度提供关卡建议。

### 3.2 “复述+答题+诊断”三位一体模式
本系统彻底摒弃了枯燥的单纯刷题，转而构建自主型学习闭环：
  1. 主动复述（Reviewing）：AI 强制要求学员使用自己的语言总结知识点，触发“主动召回”机制。若学员陷入困难，系统将启动“支架式教学”：先给出回答方向引导，若仍无法完成则降级为 A/B/C 选项引导，确保学员在不脱离引导的情况下完成认知重构。
  2. 三阶挑战（Testing）：通过“易、中、难”三个维度的挑战题验证逻辑闭环。
  3. 深度诊断（Diagnostic）：AI 会生成详细的正确率报告，并深度分析学员的误区（如：是否混淆了折现率与增长率）。在提供针对性解答后，AI 会主动询问是否需要对薄弱环节进行更深入的专题讲解。

### 3.3 后端状态机硬约束
我在后端维护了一个严密的状态机逻辑。系统存在物理级的硬约束：若未通过 100% 的诊断测试，学员将无法解锁下一章节，并回到“答题-诊断-再答题”的循环。通过循环确保每一处知识漏洞都被即时修复。

### 3.4 页面与交互革新
  - 自动化教研：利用 AI 脚本自主读取 PDF 文档，实现章节与关卡的智能划分。
  - 逻辑地图首页：抛弃列表式布局，将首页设计为“逻辑地图”。AI 会根据章节间的内在联系，以思维导图或并列模块的形式动态呈现，帮助学员构建知识体系。
  - 进度可视化：关卡模块通过颜色与图标区分完成状态，并实时展示章节内关卡的完成百分比。
  - 自由度与控制平衡：学员可自由回顾已解锁的关卡，但未完成关卡的后续路径将保持锁定状态，确保学习节奏受控。

## 4. 未来优化方向
### 4.1 深度多模态结合（当前进行中）
计划将关卡内容进一步融合多模态序。
关卡设计：
  - 初阶：通过较短的入门级视频或幻灯片建立直观感受（视频播放超过80%/幻灯片阅读至最后一张后才可触发ai教学流程），配合复述与基础练习。
  - 进阶：引入深度文本解析与复杂例题，配合中高难度挑战。
  - ai导师能动态监测当前学习状况，根据停留时长和停留内容发出“是否需要举例讲解”等提示。

### 4.2 自动化内容生产
开发 AI 自动爬虫与生成逻辑，实现视频素材、幻灯片及解析例题的自主化配置，进一步降低教研成本。

### 4.3 趣味化与表现力增强
  - 交互多元化：引入连线题、图表分析、填空等更具游戏感的答题形式。
  - 动画升级：提升“金多利”的动画流畅度与反馈真实感，增强情感连接。
