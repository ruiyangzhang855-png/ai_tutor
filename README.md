一、Cat-Pilot: AI-Driven CFA Diagnostic Tutor
Cat-Pilot 是一款基于 Next.js 16 和 DeepSeek API 开发的“关卡式”学习系统。它通过深度诊断型 AI 导师（金多利猫），确保学员从“被动阅读”转向“主动掌握”。

二、技术栈
1. Frontend: Next.js 16 (App Router + Turbopack)
2. Styling: Tailwind CSS + Shadcn/UI
3. Animation: Framer Motion
4. AI Model: DeepSeek-V3 (via OpenAI SDK)
5. Data Parsing: pdf-extraction + Node.js Scripts

三、快速启动
cd my-ai-tutor
npm run dev
