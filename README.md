## 为什么做这个项目

目前的 AI 学习工具大多是"被动"的：用户提问、AI 回答，本质是搜索引擎式交互，无法承载真正的教学——逻辑导向的内容呈现、实时的理解校验、可控的学习节奏。

Cat-Pilot 的核心理念：**AI 不应该等学员来问，而应该主动组织教学、验证理解、控制节奏。**

## 核心设计

### 1. "复述 + 答题 + 诊断"学习闭环

| 阶段 | 机制 | 教育学依据 |
|---|---|---|
| 主动复述 | 强制学员用自己的语言总结知识点后才能进入测试 | 主动召回（Active Recall） |
| 三阶挑战 | 一次性给出易/中/难 3 道题，提交后统一诊断 | 难度梯度验证逻辑闭环 |
| 深度诊断 | 生成正确率报告 + 误区分析（如"混淆了折现率与增长率"），并提供针对性补讲 | 错因归类与即时修复 |

### 2. 支架式引导降级（Scaffolding）

学员复述遇到困难时，引导逐级降级而非直接放弃：
**开放复述 → 方向提示 → A/B/C 选项引导**，确保学员始终在引导内完成认知重构。

### 3. 关卡解锁与节奏控制

- 未通过 100% 诊断测试无法解锁下一章节，回到"答题-诊断-再答题"循环
- 已解锁关卡可自由回顾，未完成关卡的后续路径保持锁定
- 首页为"逻辑地图"：AI 按章节内在联系动态生成知识结构图，配合进度可视化

### 4. 结构化 Prompt 体系

AI 导师"金多利"由结构化 system prompt 驱动，核心设计：

- **强制 JSON 状态输出**：`reply` / `nextPhase` / `canNavigate` / `diagnose` 字段，将 LLM 作为可控的系统组件而非自由聊天
- **行为约束清单**：严禁因学员说"跳过/我会了"而放行、严禁单题即时反馈（统一诊断）
- **拟人化设计**：猫系导师人设（活泼语气 + 严苛原则），降低学习工具的冰冷感

## 迭代历程（两次推翻重做）

| 版本 | 设计 | 复盘结论 |
|---|---|---|
| v1 关键词触发 | 提炼章节关键词，学员触发指定词汇推进课程 | AI 异化为诱导关键词的工具；学员复制粘贴即可"骗过"系统，学习流于表面 |
| v2 结构化测试 | 引入答题通关制度 | 增强了效果判断，但仍是"挂载题库的插件"，节奏控制与沉浸感缺失 |
| v3（当前） | 复述+答题+诊断闭环 + 关卡状态机 | 完整教学系统 |

## 技术栈

- **前端**：Next.js 16
- **模型**：DeepSeek API（结构化 JSON 输出）
- **内容生产**：AI 脚本自动解析 PDF，智能划分章节与关卡

```bash
npm install
# 配置环境变量：DEEPSEEK_API_KEY=your_key
npm run dev
```

## 已知局限与生产化方向

作为 3 天交付的验证原型，以下问题在设计上已识别，是生产化的第一优先级：

1. **解锁判定的服务端校验**：当前 `canNavigate` 由模型输出决定，存在 prompt 注入风险（学员可通过指令注入诱导模型放行）。生产方案应由后端独立判定答题对错并校验状态流转，模型输出仅作展示层参考。
2. **多模态关卡**（进行中）：初阶视频/幻灯片（播放超 80% 后触发 AI 教学）、进阶深度解析，AI 按停留时长动态提供讲解提示。
3. **自动化内容生产**：视频素材、幻灯片与例题的自主化配置。
4. **交互多元化**：连线题、图表分析、填空等游戏化题型。
